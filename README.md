# Python Recursion Tasks

Практична робота з теми **«Рекурсія»**.

## Опис

Реалізація п'яти завдань мовою Python з використанням рекурсивних функцій без циклів `for` та `while`.

## Завдання

1. `task1.py` — перевертання рядка.
2. `task2.py` — перестановка сусідніх вузлів зв'язаного списку.
3. `task3.py` — обчислення чисел Фібоначчі.
4. `task4.py` — підрахунок способів підйому сходами.
5. `task5.py` — рекурсивне піднесення числа до степеня.

## Технології

- Python 3
- Рекурсія
- Зв'язані списки
- Мемоізація

## Запуск

Для запуску завдання виконайте команду:

`python task1.py`

Аналогічно запускаються інші файли.
